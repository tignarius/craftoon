## 범위와 판정 방법

이 문서는 저장소의 구현·문서·Git 이력 및 이번 작업에 제공된 대화를 정리한 증거 색인이다. 저작권의 성립·귀속이나 독창성을 확정하는 문서는 아니다. 구현이 존재한다는 사실과 누가 아이디어·표현을 만들었는지는 구분한다.

- **구현 확인:** 특정 커밋의 코드에서 동작·구조를 확인할 수 있음.
- **사용자 결정 확인:** 제공된 대화에 사용자의 구체적 지시가 있음. 해당 대화 원본의 별도 보존은 필요함.
- **문서 기록:** 저장소 문서에 설명이 있음. 작성 당시의 설명이며 독립적인 실험·권리 증명은 아님.
- **확인 필요:** 결정자, 최초 제안 시점, 직접 작성 범위 등을 특정할 직접 자료가 없음.

2026-11-22 사용자 확인: `Yonggyu Park`·`tignarius`·`Squareplayer`는 모두 사용자 본인을 뜻한다. 이 동일인 관계는 **사용자 진술로 확인**했으며, 별도의 신원 문서를 검증한 것은 아니다. AI가 편집한 커밋도 사용자 이름으로 기록될 수 있다. 제3자 권리나 계약 관계까지 이 진술로 확정하지 않는다.

## 사용자의 제작 경위 확인·정정 (2026-11-22)

- 사용자는 Windows에서 개발을 시작한 뒤 Mac으로 이전하면서 폴더 구조가 바뀌었다고 설명했다. 개발 환경 이력에 관한 사용자 진술이며, 특정 Git 경로 단절의 직접 원인·시점은 별도 확인 대상이다.
- 사용자는 이전의 ‘앱을 먼저 만들었다’를 **‘웹을 먼저 만들었다’**로 정정했다. 현재 남아 있는 최초 웹·앱 Git 기록의 순서와도 부합한다.
- 사용자는 **프로젝트 아이디어는 모두 본인의 아이디어**라고 밝혔다. 아래 초기 설계의 구상·방향은 이 진술을 근거로 사용자 기획으로 기록한다. 이는 코드·수학 알고리즘·외부 라이브러리의 모든 표현을 사용자가 직접 작성했다는 뜻은 아니다.
- 사용자는 초기에 **Gemini**를 사용해 제작했고, 가장 최근에는 **Codex**를 사용했다고 밝혔다. 이미지에는 당시 **ChatGPT도 한 번 사용했던 것 같다**고 설명했다. ChatGPT 사용은 확정 진술이 아닌 회고이므로 **확인 필요**로 유지한다.
- 저장소 주소로 `https://github.com/tignarius/craftoon.git`를 지정했다. 로컬 origin과 주소 일치는 재확인했다. 과거 웹 브랜치의 푸시 여부와 실제 작업별 생성 기록은 별도로 확인해야 한다.

아래 표의 초기 작업에서 ‘최초 구상자·결정 경위 확인 필요’는 **이번 진술로 일반적인 기획 주체가 보완됐으며**, 남은 확인 대상은 해당 결정의 당시 원문·시각과 세부 구현 작성 범위다. 최근 대화에서 AI가 구체적으로 제안한 구현 수치·방법은 그대로 AI 기여로 구분한다.

## 시각 자료의 경계

웹 `design/splash_screen_prompt.txt`에는 보라→파랑 그라데이션, 손글씨풍 Craftoon 제목, `Create Your Story`, 만화 패널 아이콘, 기기 프레임 제외 등이 구체적으로 기재돼 있다. 해당 텍스트가 `web-legacy`에 존재하고 현재 웹 폴더와 같다는 것은 확인했다. 프롬프트를 누가 작성했는지, 실제 어느 생성기에 언제 입력했는지, 어떤 출력물을 얼마나 수정했는지는 **확인 필요**다.

`Gemini_Generated_Image_*.png`, `Generated Image ...` 파일명은 생성형 이미지 사용을 시사하는 흔적이며, 파일명만으로 모델·생성자·권리 범위를 확정하지 않는다. `splash_comic.ai`의 `.ai`는 Illustrator 문서 확장자다. SVG의 `Generator: Adobe Illustrator 24.3.0` 표기는 내보내기 도구의 흔적일 뿐 인간 수작업의 양을 증명하지 않는다. 이미지·폰트·아이콘의 출처와 편집 전후 파일을 추가 보존해야 한다.

## 추가 확인할 자료

1. 초기 기획 메모, 화면 스케치, 프롬프트·생성 결과·선택/수정 지시가 연결된 원본 대화.
2. 세 이름이 동일인이라는 사용자 진술은 확보됨. 다른 참여자 유무, 외부 자산 권리·계약 관련 자료는 별도 확인.
3. 웹 먼저 제작 및 초기 Gemini·최근 Codex 사용 진술은 확보됨. 실제 최초 작업 시각, 도구별 생성 범위, ChatGPT 이미지 사용 회고를 원본 자료로 확인.
4. 제3자 리소스 원본·라이선스와 실제 앱에 포함된 자산까지의 변환 경로.
