## 판정 기준

이 목록은 확인 가능한 기여를 구분한다. 코드의 존재·완성도, 영문 주석, 커밋 작성자, 파일명만으로 AI 또는 인간 단독 창작이라고 판정하지 않는다. 생성형 AI의 출력물, 사람이 내린 목적·선택·수정 지시, 기존 라이브러리·템플릿은 서로 다른 항목이다. 이 자료로 창작 기여 비율이나 법적 권리 귀속을 산정하지 않는다.

직접 확인 가능한 최근 대화는 이번 문서 작성 작업에 제공된 대화 맥락을 의미한다. 해당 대화의 전체 원본·메시지 ID·내보내기 파일은 이 저장소에서 확인하지 못했다. 재현 가능한 영구 증빙을 위해 사용자 원본 대화 보존은 **확인 필요**다. 대화에서 날짜가 따로 명시되지 않은 요청의 시각을 Git 시각으로 대체하지 않았다.

## 3. 외부 구성요소를 별도로 표시할 항목

- **React, React Native, Vite, Expo, Skia, Hermes, CocoaPods 및 기타 패키지:** 각 `package.json`, `package-lock.json`, `ios/Podfile.lock`의 버전/패키지 기록으로 식별한다. 각 코드와 라이선스는 외부 권리 영역이며 프로젝트 고유 코드와 구분한다. 의존성 전체의 라이선스 검토 완료 여부는 **확인 필요**다.
- **Lucide/Feather 아이콘:** 앱의 `lucide-react-native` 사용 및 [동봉 라이선스](../manual/lucide-LICENSE.txt) 확인. 앱에서 선택·배치·조합한 부분과 외부 아이콘 원형을 구분한다.
- **PencilKit·StoreKit·PDFKit 및 iPadOS 제공 UI:** `ios/Craftoon/`의 import와 API 사용에서 확인. 시스템 팔레트·결제창 자체를 독자 제작 UI로 기재하지 않는다.
- **Hermes dSYM:** 공식 배포물을 받아 검증·연결하는 스크립트는 이번 AI 지원 구현이고, 심볼 원본은 React Native 배포물이다. 출처·체크섬은 [검증 기록](../HERMES_DSYM.md)에 있다.
- **제목 글꼴·스플래시 이미지·앱 아이콘:** 디자인 폴더의 원본/변형 흔적 외에 개별 생성·구매·라이선스 계약과 최종 채택 대응표는 **확인 필요**다.

## 4. 보완할 증빙

1. 초기 웹 제작과 앱 제작 대화 원본을 날짜·도구·메시지 식별자와 함께 별도 보존.
2. 자산마다 입력 프롬프트 → 원본 출력 → 선택/반려 → 사람의 편집본 → 최종 앱 자산의 대응표 작성.
3. 인간 기여자별 기획·드로잉·편집·코딩·검수 범위와 관련 계약 확인.
4. 소스와 이미지의 AI 기여 비율을 숫자로 만들지 말고, 확인 가능한 작업 단위로 기록.
5. ‘웹 먼저 제작’으로 정정됐고 저장소 주소도 확인됨. 남은 항목은 해당 원격에 웹 이력을 푸시한 과거 기록과 초기 작업 원본 확인.

이 문서에 ‘확인 필요’라고 적힌 사항은 미사용·미창작·권리 부재를 뜻하지 않는다. 현재 조사 범위에서 증거가 충분하지 않다는 뜻이다.
