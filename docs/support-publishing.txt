This is a static English support page. It has no JavaScript, analytics, external
fonts, contact form, or app build step. Email links open the visitor's email app.
Only docs/support is uploaded by the workflow; other repository documents,
source code, screenshots, and copyright research are not included in the Pages artifact.
GitHub may impose repository visibility/plan requirements for Pages.

PUBLICATION
1. Commit and push docs/support (including its images) and support-pages.yml to the existing
   tignarius/craftoon GitHub repository. Include this guide if useful.
   Do not include unrelated pending app changes or build artifacts.
2. In GitHub: repository Settings > Pages > Build and deployment > Source,
   select GitHub Actions. If Pages already serves another website, do not
   replace it; choose a separate repository or integrate the support page first.
3. In Actions, select Publish Craftoon Support, then Run workflow on the branch
   containing these files. It runs only when manually triggered.
4. Wait for a successful deployment. Use the exact URL displayed by the job.
5. Open the deployed page without signing in and test the email links.
